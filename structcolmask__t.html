Detailed Description

Column bit masks of a sparse binary matrix A (e.g., the logical operators L), see colmask_from_csr(): column j is the set of rows i with A[i][j]=1, stored in kw words. The syndrome A e of a sparse vector e is then the XOR of the masks of its columns (colmask_syndrome_non_zero()), which takes O(|e| kw) operations instead of O(nnz(A)) for sparse_syndrome_non_zero().
