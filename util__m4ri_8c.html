Check whether the all-ones vector lies in the row span of a binary CSR matrix H over GF(2).

When 1_n is in rowspan(H), every vector c in ker(H) satisfies 1_n . c = 0 (mod 2), so all codewords have even Hamming weight.

Parameters
HBinary matrix in compressed CSR form.
Returns
1 if the all-ones vector is in rowspan(H), 0 otherwise.

int csr_cols_rank ( const csr_t *const HT,
const int cnt,
const int cols[],
cols_ws_t *const ws )

Rank of a set of columns of a sparse binary matrix H.

A dense Gaussian elimination of the cnt columns restricted to the rows they touch (duplicate entries cancel mod 2). A nonempty codeword C (H 1_C = 0) is irreducible, i.e., it is not the union of two disjoint nonempty codewords (no nonempty proper subset of C has zero syndrome), if and only if the rank of its columns is |C| - 1.

Parameters
HTThe transpose of H in CSR form (row j: the rows of the column j of H).
cntNumber of columns.
colsThe columns (distinct).
wsWorkspace for H (see cols_ws_init()).
Returns
The rank of the columns.
