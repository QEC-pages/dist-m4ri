Detailed Description

Workspace of csr_cols_rank() and csr_cols_dependency() (one per thread, see cols_ws_init()): the rows of H touched by a set of columns are numbered in the order found (rmap, all -1 between the calls), and the columns are stored as dense bit vectors over these rows (bits, reallocated as needed).
