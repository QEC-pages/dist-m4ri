Detailed Description

The table of the canonical classes of the minimum weight in the uniform RW steps (Stage 5; under the codeword mutex): the uniform-step incidence count of each class and the set of the raw codewords, keyed by 64-bit Zobrist hashes (see rw_set_key()).
